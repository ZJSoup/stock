# Momo Bot 设计文档

**日期**：2026-09-29
**主题**：按 Ross Cameron（Warrior Trading）低流通盘动量日内策略，构建全自动交易 bot
**起始资金**：$2,000，IB 现金账户，纯现金无杠杆
**状态**：设计已确认，待写实现计划

---

## 1. 背景与目标

Ross Cameron 的策略本质是**低流通盘动量剥头皮**：每日用五支柱选出全市场最"明显"的暴涨股，等首次回踩后的 crossing candle 入场，目标先测试日内高点，依据 K 线形态与逐笔卖压快速离场。

本项目将其中**可机械化的部分**做成全自动 bot，与 stock folder 下现有 SPY 期权策略并列、互不干扰。

已知局限（用户已知悉并接受）：

- Level 2 盘感、隐藏卖家在 v1 不实现（留接口）；
- 新闻催化剂与 float 数据用免费源近似，可能缺失；
- 低价小盘股有滑点、闪崩、盘中停牌、流动性消失风险。

**强制前提**：先跑纸盘，达到放行门槛（第 8 节）后才允许上 $2,000 真钱。

## 2. 战绩参考（Ross 挑战数据，仅作参照，非收益承诺）

- $2,000 → $105,951.28，46 天，113 笔；
- 胜率 70%（80 胜 33 负），盈亏比约 1:1；
- 每笔期望 ≈ +0.4R；Schwab 现金账户、无杠杆。

## 3. 架构总览

**方案 A：纯事件驱动单进程 bot，全部基于 IB 原生 API。**

- 扫描：IB `ScannerSubscription`（TOP_PERC_GAINERS + 价格/成交量参数）；
- RVOL：日线历史数据计算 50 日均量；
- 信号：1 分钟 K 线（结构/形态）+ 逐笔 tick 滚动统计主动卖压；
- 执行：可成交限价单（marketable limit），入场后立即挂止损；
- 状态机驱动全流程；
- 依赖仅 ib_insync / pandas / numpy / yfinance（现有 requirements），不新增外部服务。

## 5. 五支柱落地

| 支柱 | 阈值 | 来源 / 算法 |
|---|---|---|
| ① 涨幅 | ≥10%（A+ ≥30%） | IB 扫描参数 + `(last − prevClose)/prevClose` 复核 |
| ② RVOL | ≥5× | 今日累计量 ÷ 50 日均量（reqHistoricalData 计算并缓存） |
| ③ 新闻 | 有催化剂优先 | yfinance 新闻列表佐证（可降级）；**无新闻不否决**，只影响分级 |
| ④ 价格 | $2–20（A+ $5–10） | 实时 last；扫描器价格参数预过滤 |
| ⑤ Float | <20M（A+ <10M） | yfinance sharesfloat；缺失时用 IB fundamentals sharesOutstanding 近似，置信度低则降一档 |

质量分级（决定仓位系数）：

- **A+**：5/5、涨幅≥30%、$5–10、float<10M → 100%
- **A**：5/5 → 80%
- **B**：缺新闻（4/5，轧空妖股）→ 50%
- 其他 → 不做

明显性偏好：只从全市场涨幅榜前 5 中选择；前一天有大妖股时优先同类型（外资/中国背景），用 symbol 元数据 + 昨日涨幅记忆简单匹配。

## 6. 状态机

```
IDLE ──7:00到──► SCANNING
                   │ 五支柱筛候选，订阅 K 线/tick
                   ▼
                 WATCH_PULLBACK  ◄────────────┐
                   │ 急涨后首次回踩筑底         │
                   ▼                           │
                 WAIT_BREAK                    │
                   │ crossing candle 确认       │
                   ▼                           │
                 ENTERING ──► IN_POSITION ◄──┐
                                  │  ▲       │
                    ┌─────────────┼──┘       │
                    ▼             │          ▼
                 STOPPED       TARGET1    EXIT信号
                 (止损)        (减半仓)     (全平)
                    │                          │
                    └──────────┬───────────────┘
                               ▼
                           DONE（当日锁定）
（TARGET1 不是终态：减半仓、止损上移成本后仍处于 IN_POSITION，剩余仓位等 EXIT 信号）
```

硬约束（任何状态生效）：

- 现金账户：**每天 1 只票、1 个 round-trip**（仓位可分批进/出）；
- 时间窗 7:00–10:00 ET，10:00 后只许平仓；
- 日亏 15% → 全平 → DONE；
- 当日最高浮盈回吐 50% → 全平 → DONE；
- DONE 锁持久化，重启进程不可解锁。

### 6.1 入场规则

1. 存在急涨腿（5 分钟内涨幅 ≥15%）；
2. 首次回踩：≥2 根 K 线不创新高，回撤为急涨腿的 25%–70%；
3. 筑底：下影线，或连续两根低点差 <0.3%；
4. Crossing candle：当前 K 线高点突破回踩中最高阴线高点 → 触发；
5. 止损 = 回踩最低点下方小 buffer；入场前验算 **R:R ≥ 1:1**（到日内高点空间 ÷ 止损距离），不满足放弃。

下单：可成交限价单（last + 小偏移）；入场成交后立即挂止损，两步确认后才是 IN_POSITION，否则撤单回 SCANNING。

### 6.2 出场规则（任一触发）

1. **Tape 卖压爆发**：30 秒滚动窗口主动卖成交占比 ≥65% 且金额超阈值；
2. **上影线 / 高位十字星**：上影 ≥ 实体 2 倍，或高位 doji；
3. **量价背离**：价格新高但最近 3 根 K 线量能递减 ≥30%；
4. **硬止损**：跌破回踩低点；减半仓后止损上移至成本。

分批：触日内高点（第一目标）减 1/2、止损上移成本，剩余凭信号 2/3 出。v1 不做极热市场加仓。

## 7. 风控、异常与崩溃恢复

### 7.1 三层风控

1. **账户层**：日亏 15%、浮盈回吐 50% → 全平 + 当日锁定；10:00 后只平仓；每日 1 票 1 round-trip；
2. **交易层**：入场前 R:R ≥1:1；止损随入场挂出杜绝裸头寸；股数 = `min(风险股数, 已结算资金可买股数) × 质量系数`；现金账户只用**已结算现金（settled cash）**下单，防止 good faith violation；单笔风险 10%（$2,000 时 $200）；
3. **异常市场**：
   - 停牌（halt）：撤挂单，复牌后只按预设止损处理，不新开；
   - 数据中断 >30 秒告警，>2 分钟保守平仓；
   - 断线自动重连，重连后按对账恢复，不凭内存状态下单。

### 7.2 崩溃恢复

- 每次状态切换原子写 `~/.local/share/stock-momo/state.json`（临时文件 + rename）；
- 快照：状态、conId、股数、入场价、止损价、当日已实现盈亏、最高浮盈、DONE 锁；
- 重启以券商真实持仓/挂单为准对账：
  - 有仓位无记录 → 重建 IN_POSITION、补挂止损，不加仓；
  - DONE 锁存在 → 只监控不开仓；
  - 对账不平 → 不交易、写日志等人工。

### 8.2 纸盘 → 真钱放行

1. launchd 每交易日 6:55 启动，连 paper gateway（4002/7497）；
2. journal 记录每笔 setup、分级、进出场、滑点假设、熔断事件；
3. 至少 **20 个有实际交易的交易日、≥10 个完整 setup**（用户 2026-09-29 裁定：无交易日不计入 trading_days，门槛从严，`trading_days` = journal 中 distinct 的有交易日期）；
4. 全部满足：累计净盈利、胜率 ≥60%、最大回撤 ≤15%、零风控违规（裸头寸/熔断未执行/时间窗外开仓/结算违规）；
5. 由用户**手动**切 mode=live 并入金 $2,000；代码不提供自动切换；
6. live 首周单笔风险减半（5%）软启动。
